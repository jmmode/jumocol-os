## REGLAS DE PRODUCCIÓN

1. **Un Short por día, sin excepción.** La consistencia es el algoritmo.
2. **Un largo por semana, sábado o martes.** Máxima visibilidad.
3. **Todo guion nace de fuente canónica.** Cero datos inventados.
4. **Fase de calibración:** Julián revisa antes de publicar (semanas 1–2). Semanas 3–4: revisión solo de excepciones.
5. **Medir tokens por pieza.** Si un prompt consume >X tokens para el mismo output, optimizar.
6. **Redistribuir:** cada Short → TikTok + Reels + X el mismo día. Cada largo → clips de 3 Shorts derivados.
7. **No perseguir tendencias ajenas.** El contenido deriva del ecosistema propio. La autenticidad es el diferenciador.
